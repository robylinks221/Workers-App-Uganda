REPLACE THESE FILES
-------------------
Copy the files from this package into:

~/StudioProjects/workersapp/

Keep the same lib/ folder structure and allow Finder to replace the existing files.

VERIFY
------
cd ~/StudioProjects/workersapp

dart format lib/widgets/premium_buttons.dart lib/features/profile/worker_public_profile_screen.dart lib/homeowner_job_details.dart lib/worker_job_details.dart

flutter analyze lib/widgets/premium_buttons.dart lib/features/profile/worker_public_profile_screen.dart lib/homeowner_job_details.dart lib/worker_job_details.dart

Warnings about unused old helper widgets do not stop the build.
Errors must be corrected before running.

RUN
---
Make sure Laravel Sail is running:

cd ~/Development/worker_app_api
./vendor/bin/sail up -d
./vendor/bin/sail artisan optimize:clear

Then in another Terminal:

cd ~/StudioProjects/workersapp
~/Library/Android/sdk/platform-tools/adb reverse tcp:80 tcp:80
flutter run -d RZCY91RKGMA
